# Ticketbox — выдача экзаменационных билетов

Лабораторная работа №2 на Python 3.11+ с интерфейсом на CustomTkinter.

Преподаватель выбирает группу и студента и нажимает «Выдать билет».
Программа тянет случайный билет, показывает его номер и три вопроса и
сразу записывает выдачу в журнал `results.xlsx`.

- Группы и студенты берутся из `students.xlsx`: лист — группа, колонка A —
  фамилия, колонка B — имя.
- Билеты берутся из `tickets.docx`: заголовок «Билет N» и три вопроса
  (обычным текстом «1. …» или нумерованным списком Word). Неполные и
  нераспознанные билеты пропускаются, причина пишется в `app.log`.
- Студент, который уже получал билет, получает тот же номер с пометкой
  «повтор».
- Если журнал открыт в Excel, программа просит закрыть файл и повторить,
  а не падает.
- Светлая и тёмная тема (по системе, переключатель в шапке).

## Установка и запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

Файлы ищутся в текущей папке, а если их там нет — берутся примеры из
`data/`.

## Тесты

```powershell
python -m pytest
```

Unit-тесты логики и UI-тесты окна: настоящее окно открывается за
пределами экрана, тест выбирает пункты в списках, нажимает кнопки и
проверяет, что показано. Диалоги подменяются.

## Устройство

| Модуль | Назначение |
|--------|-----------|
| `ticketbox/core/roster.py` | группы и студенты |
| `ticketbox/core/question_bank.py` | разбор `tickets.docx` автоматом состояний |
| `ticketbox/core/result_book.py` | журнал, правило повтора, ошибка `BookBusy` |
| `ticketbox/core/workspace.py` | папка с данными и лог |
| `ticketbox/gui/` | главное окно, окно билета, цвета и шрифты |
| `main.py` | запуск |

## Ветки

| Ветка | Содержимое |
|-------|------------|
| `01-core` | список студентов, разбор билетов, журнал результатов |
| `02-gui` | главное окно и окно билета |
| `03-tests` | unit- и UI-тесты, README |

Каждая ветка основана на предыдущей и вливается в `main` отдельным
Pull Request в этом порядке.
